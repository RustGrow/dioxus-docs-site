# Основные концепции

Dioxus — это фреймворк Rust для создания кроссплатформенных приложений с единой кодовой базой. Каждое приложение использует пользовательский интерфейс (UI) для отображения контента и позволяет пользователю совершать действия. UI строится из небольших единиц, таких как кнопки, текст и изображения, а затем организуется в компоненты, которые инкапсулируют функциональность. Приложения Dioxus создаются путем объединения компонентов в более крупное интерактивное дерево.

![Дерево виджетов](/assets/07/widget-tree.png)

С Dioxus вы просто объявляете, как должно выглядеть ваше приложение, и легковесный рантайм Dioxus обеспечивает правильный рендеринг виджетов на вебе, десктопе и мобильных устройствах.

## Обзор на высоком уровне

Dioxus основывается на десятилетиях исследований UI. Создание интерактивных, красивых и эффективных пользовательских интерфейсов может быть сложной задачей. Мы разработали Dioxus, чтобы справиться со сложностью фронтенд-разработки с помощью простой ментальной модели:

1. Пользовательские интерфейсы строятся *декларативно* для описания макета и стиля виджетов
2. Состояние приложения хранится в небольших, компонуемых функциях, называемых «хуками"
3. Изменения состояния выполняются в ответ на взаимодействие пользователя, что приводит к «перерисовке"

Ручное создание и модификация элементов UI может быть утомительной и подверженной ошибкам задачей. Декларативный подход к UI, который использует Dioxus, требует некоторой практики для освоения, но в конечном итоге приводит к эффективному и легкому в поддержке фронтенд-коду. Мы рекомендуем тщательно пройтись по Основным концепциям, чтобы понять, как работают модель UI и реактивности Dioxus.
