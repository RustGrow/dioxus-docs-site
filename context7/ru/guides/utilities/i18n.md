# Интернационализация

Если ваше приложение поддерживает несколько языков, крейт [dioxus-i18n](https://github.com/dioxus-community/dioxus-i18n) содержит вспомогательные средства, облегчающие работу с переводами в вашем приложении.

Пример можно найти [здесь](https://github.com/dioxus-community/dioxus-i18n/blob/main/examples/dioxus-desktop.rs).
