# Публикация

После того как вы собрали своё приложение, вам нужно будет опубликовать его где-нибудь. Этот справочник описывает различные методы публикации вашего десктопного или веб-приложения.

## Веб: Публикация с помощью GitHub Pages

Отредактируйте свой `Dioxus.toml`, чтобы указать `out_dir` на папку `docs` и `base_path` на имя вашего репозитория:

```toml
[application]
# ...
[web.app]
base_path = "your_repo"
```

Затем соберите приложение и опубликуйте его на GitHub:

- Убедитесь, что GitHub Pages настроен для вашего репозитория на публикацию статических файлов в директории docs
- Соберите приложение в директорию `docs` с помощью:
```sh
dx bundle --out-dir docs
```
- Переместите статический контент из `docs/public` в `docs`
```sh
mv docs/public/* docs
```
- Сделайте копию файла `docs/index.html` и переименуйте копию в `docs/404.html`, чтобы ваше приложение работало с клиентской маршрутизацией:
```sh
cp docs/index.html docs/404.html
```
- Добавьте и закоммитьте с помощью git
- Отправьте на GitHub

## Десктоп: Создание установщика

Десктопное приложение Dioxus использует библиотеку WebView вашей операционной системы, поэтому оно легко переносится и может быть распространено на другие платформы.

В этом разделе мы рассмотрим, как упаковать ваше приложение для macOS, Windows и Linux.

## Подготовка приложения к упаковке

В зависимости от вашей платформы вам может потребоваться добавить дополнительный код в файл `main.rs`, чтобы подготовить приложение к упаковке. В Windows вам нужно добавить атрибут `#![windows_subsystem = "windows"]` в файл `main.rs`, чтобы скрыть окно терминала, которое появляется при запуске приложения. **Если вы разрабатываете на Windows, используйте это только при упаковке.** Это отключит терминал, поэтому вы не получите никакие логи. Вы можете защитить это за фичей, например:

```toml
# Cargo.toml
[features]
bundle = []
```

А затем в вашем `main.rs`:

```rust
#![cfg_attr(feature = "bundle", windows_subsystem = "windows")]
```

## Добавление ресурсов в приложение

Если вы хотите упаковать ресурсы вместе с приложением, вы можете либо использовать их с помощью крейта `manganis` (подробнее на странице [ресурсов](../../essentials/ui/assets.md)), либо включить их в файл `Dioxus.toml`:

```toml
[bundle]
# Список файлов для включения в пакет. Они могут содержать glob-шаблоны.
resources = ["main.css", "header.svg", "**/*.png"]
```

## Установка `dioxus CLI`

Первое, что мы сделаем, — установим [dioxus-cli](https://github.com/DioxusLabs/dioxus/tree/main/packages/cli). Это расширение для cargo сделает очень лёгкой упаковку нашего приложения для различных платформ.

Для установки просто выполните

`cargo install dioxus-cli`

## Сборка

Чтобы упаковать ваше приложение, вы можете просто запустить `dx bundle --release` (также добавьте `--features bundle`, если вы используете это, см. [это](#подготовка-приложения-к-упаковке) для подробностей), чтобы создать финальное приложение со всеми оптимизациями и встроенными ресурсами.

После выполнения команды ваше приложение должно быть доступно в `dist/bundle/`.

Например, приложение для macOS будет выглядеть так:

Отлично! И оно весит всего 4,8 МБ — невероятно легко!! Поскольку Dioxus использует нативный WebView вашей платформы, приложения Dioxus чрезвычайно эффективны по памяти и не расходуют зря батарею.

> Примечание: не весь CSS работает одинаково на всех платформах. Обязательно просмотрите CSS вашего приложения на каждой платформе — или веб-браузере (Firefox, Chrome, Safari) перед публикацией.
