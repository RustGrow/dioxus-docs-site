# Создание проекта

После установки Dioxus CLI вы можете использовать его для создания собственного проекта!

## Инициализация проекта

Сначала выполните команду `dx new`, чтобы создать новый проект.

> Команда клонирует этот [шаблон](https://github.com/DioxusLabs/dioxus-template), который используется для создания приложений Dioxus.
>
> Вы можете создать проект на основе другого шаблона, передав аргумент `template`:
> ```
> dx new --template gh:dioxuslabs/dioxus-template
> ```

Затем перейдите в новый проект с помощью `cd project-name` или просто откройте его в IDE.

> Убедитесь, что целевая платформа WASM установлена перед запуском проектов.
> Вы можете установить цель WASM для Rust с помощью rustup:
> ```
> rustup target add wasm32-unknown-unknown
> ```

Наконец, запустите свой проект с помощью `dx serve`! CLI сообщит вам адрес, на котором запущен сервер, а также дополнительную информацию, например предупреждения кода.
