# Настройка инструментов

Прежде чем мы начнем, убедитесь, что вы следовали инструкциям на странице [Начало работы](../getting-started/index.md) по установке необходимых зависимостей. Мы будем в основном разрабатывать *HotDog* как веб-приложение, но мы все же рекомендуем настроить соответствующие инструменты для десктопной и мобильной разработки.

## Чеклист

Мы рассмотрели инструкции по установке в [Начале работы](../getting-started/index.md), но сначала проверьте свою настройку:

- Rust и Cargo установлены
- Целевая платформа wasm32-unknown-unknown для Rust установлена
- `dioxus-cli` установлен и обновлен
- Установлены системно-специфичные зависимости

Используйте команду `dx doctor`, чтобы увидеть, что использует `dx` для сборки вашего приложения.

## Все команды

Прежде чем продолжить, убедитесь, что у вас установлен и обновлен `dioxus-cli`. Проверьте, что возвращаемая версия соответствует этому руководству, запустив:

```sh
dx --version
```

Вы также можете запустить `dx help`, которая даст вам список полезных команд и некоторую информацию о том, как использовать `dx`.

```txt
Build, Bundle & Ship Dioxus Apps

Usage: dx [OPTIONS] <COMMAND>

Commands:
  build      Собрать проект Dioxus и все его ассеты
  translate  Перевести исходный файл в код Dioxus
  serve      Собрать, отслеживать и обслуживать проект Dioxus и все его ассеты
  new        Создать новый проект для Dioxus
  init       Инициализировать новый проект для Dioxus в текущей директории (по умолчанию). Попытается сохранить ваш проект в хорошем состоянии
  clean      Очистить артефакты сборки
  bundle     Собрать приложение Dioxus в готовый к распространению объект
  fmt        Автоматически форматировать RSX
  check      Проверить проект на наличие проблем
  run        Запустить проект без горячей перезагрузки
  config     Управление файлом конфигурации Dioxus
  help       Вывести это сообщение или справку по данной подкоманде(ам)

Options:
      --verbose      Использовать подробный вывод [default: false]
      --trace        Использовать вывод трассировки [default: false]
      --json-output  Выводить логи в формате JSON
  -h, --help         Вывести справку
  -V, --version      Вывести версию
```

Если `dx` установлен правильно, то вы готовы продолжить!
