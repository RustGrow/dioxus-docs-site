# Основные концепции

Dioxus — это фреймворк на Rust для создания кроссплатформенных приложений с единой кодовой базой. Каждое приложение использует пользовательский интерфейс (UI) для отображения контента и позволяет пользователю совершать действия. UI строится из маленьких единиц, таких как кнопки, текст и изображения, а затем организуется в компоненты, которые инкапсулируют функциональность. Приложения Dioxus создаются путём объединения компонентов в более крупное интерактивное дерево.

![Widget Tree](/assets/07/widget-tree.png)

С Dioxus вы просто декларируете, как должно выглядеть ваше приложение, и лёгкий рантайм Dioxus гарантирует, что ваши виджеты корректно рендерятся на вебе, десктопе и мобильных устройствах.

## Обзор на высоком уровне

Dioxus основывается на десятилетиях UI-исследований. Создание интерактивных, красивых и эффективных пользовательских интерфейсов может быть сложным. Мы спроектировали Dioxus для решения сложности фронтенд-разработки с помощью простой ментальной модели:

1. Пользовательские интерфейсы конструируются *декларативно*, чтобы описать раскладку и стиль виджетов
2. Состояние приложения хранится в маленьких, компонуемых функциях, называемых "хуками"
3. Изменения состояния выполняются как реакция на пользовательское взаимодействие, что приводит к "повторному рендерингу"

Ручное создание и изменение UI-элементов может быть утомительным и подверженным ошибкам. Декларативный подход к UI, который использует Dioxus, требует некоторого обучения, но в конечном итоге приводит к эффективному и легко поддерживаемому фронтенд-коду. Мы рекомендуем тщательно пройти через Основные Концепции, чтобы понять, как работают UI и модель реактивности Dioxus.
