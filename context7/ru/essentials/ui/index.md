# Построение пользовательских интерфейсов

Добро пожаловать в Dioxus! Эта первая глава научит вас, как создавать красивые пользовательские интерфейсы на Rust и Dioxus.

Dioxus позволяет писать пользовательские интерфейсы на HTML и CSS. В вебе ваш UI является нативным и доступным, а на десктопе и мобильных устройствах ваши виджеты рендерятся либо в webview, либо нативно с гибридными нативными компонентами.

HTML и CSS позволяют создавать очень красивые, богатые, интерактивные впечатления. Лучшие компании мира используют HTML и CSS для своих сайтов и приложений. Даже этот док-сайт построен на HTML и CSS:

## Что даёт вам Dioxus

Dioxus даёт вам все инструменты, необходимые для использования HTML, CSS и Rust во всей их красе.

Это включает:

- Горячую перезагрузку для Rust-кода, UI, стилей и ассетов
- Кроссплатформенные рендереры для веба, десктопа и мобильных устройств
- Систему реактивности для управления и обновления состояния
- Растущий SDK кроссплатформенных API
- Бэкенд-интеграцию для создания fullstack веб-приложений
- Инструменты для сборки и развёртывания в production

Вы можете делать в Dioxus всё, что могли бы делать с HTML и CSS в одиночку.

## Что дают вам HTML и CSS

HTML и CSS — мощные технологии (хотя и с большим багажом), которые упрощают создание красивых UI, работающих на миллиардах устройств.

HTML и CSS дают вам множество инструментов:

- Несколько алгоритмов раскладки (flexbox, grid, table, float, block и т.д.)
- Стили для темизации на уровне приложения
- Стили для каждого элемента
- Отличную доступность и поддержку скринридеров
- Встроенную поддержку SVG
- CSS-анимации
- Мультимедийные элементы, такие как `img`, `video` и `audio`
- и многое другое!

HTML и CSS могут быть не *абсолютно лучшими* инструментами для работы с UI, но они широко используются, работают почти везде и имеют огромную документацию.

## Что даёт вам Rust

Зачем писать UI-фреймворк на Rust? Зачем создавать приложение на Rust? Rust изначально был предназначен для системного программирования, хотя мы в Dioxus работаем над тем, чтобы сделать его подходящим для высокоуровневого программирования, такого как разработка приложений.

У Rust довольно крутая кривая обучения, но выгоды огромны:

- Отличные, стандартизированные инструменты (cargo, rustc)
- Огромная экосистема и отличный менеджер пакетов (crates.io, Cargo.toml)
- Работает везде — Mac, Windows, Linux, iOS, Android, Web и т.д.
- Сильная система типов, которая предотвращает многие логические баги на этапе компиляции
- Отличная производительность, соперничающая с такими языками, как C / C++
- Надёжность даже в масштабе

Есть и недостатки, такие как более медленное время компиляции, крутая кривая обучения и эргономические неудобства. Наша цель — улучшить опыт "высокоуровневого Rust", чтобы он был на уровне таких языков, как TypeScript, но с добавленными преимуществами Rust.

Мы продвинули Rust *настолько* далеко, что выступили с длинным докладом на RustConf 2025, чтобы поговорить о нашей работе над такими вещами, как hot-patching и automatic ref-counting.
