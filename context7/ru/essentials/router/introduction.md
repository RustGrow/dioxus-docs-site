# Введение

По мере роста вашего приложения бывает полезно организовать его в виде нескольких страниц или представлений, между которыми можно переключаться. В веб-приложении каждое представление имеет связанный с ним URL, который можно сохранить и поделиться. Маршрутизатор Dioxus помогает управлять состоянием URL вашего приложения. Он предоставляет типобезопасный интерфейс, который проверяет все маршруты на этапе компиляции, предотвращая ошибки во время выполнения.

## Установка маршрутизатора

Чтобы начать, добавьте функцию `router` в зависимость `dioxus` в вашем `Cargo.toml`:

```toml
[dependencies]
dioxus = { version = "0.7", features = ["router"] }
```

## Создание перечисления Routable

Ядром маршрутизатора является ваше перечисление `Routable`. Вы будете использовать это перечисление во всём приложении для навигации между различными страницами. Каждый вариант перечисления — это отдельная страница представления в вашем приложении, которая обрабатывает:

1. Разбор вашего маршрута из URL
2. Отображение вашего маршрута в виде URL
3. Рендеринг вашего маршрута в виде компонента

Чтобы создать перечисление `Routable`, вам нужно вывести `Routable` с атрибутом `#[route(..)]` для каждого варианта, который описывает формат маршрута. У вас должен быть компонент в области видимости, имя которого совпадает с именем каждого варианта для рендеринга маршрута:

```rust
use dioxus::prelude::*;

    #[derive(Clone, Debug, PartialEq, Routable)]
    enum Route {
        #[route("/")]
        Home,

        #[route("/about")]
        About,

        #[route("/user/:id")]
        User { id: u32 },
    }

    #[component]
    fn Home() -> Element {
        rsx! { "Welcome to the home page!" }
    }

    #[component]
    fn About() -> Element {
        rsx! { "This is the about page." }
    }

    #[component]
    fn User(id: u32) -> Element {
        rsx! { "User page for user with id: {id}" }
    }
```

## Рендеринг маршрутизатора

Теперь, когда вы определили свои маршруты, вы можете использовать компонент `Router` для их рендеринга. Компонент `Router` принимает ваше перечисление `Routable` в качестве общего аргумента для определения обработки разбора и рендеринга маршрутов.

```rust
fn main() {
        dioxus::launch(|| rsx! { Router::<Route> {} });
    }
```

## Ссылка на ваш первый маршрут

Для навигации между маршрутами вы можете использовать компонент `Link`, предоставляемый маршрутизатором. Компонент `Link` принимает свойство `to`, которым может быть либо непроверенная строка маршрута, либо вариант вашего перечисления `Routable`:

...

```rust
#[component]
        fn Home() -> Element {
            rsx! {
                div {
                    "Welcome to the home page!"
                    Link { to: Route::About, "Go to About Page" }
                }
            }
        }
```
