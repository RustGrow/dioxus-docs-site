# Dioxus Fullstack

Почти все приложения нуждаются в удалённом сервере для хранения и обновления данных пользователя. Dioxus предоставляет ряд fullstack-утилит для создания сервера вашего приложения наряду с клиентом. С Dioxus Fullstack вы можете создавать *и* фронтенд, *и* бэкенд вашего приложения полностью на Rust!

Dioxus Fullstack глубоко интегрируется с популярным фреймворком [Axum](https://docs.rs/axum/latest/axum/), что упрощает быстрое добавление сложной функциональности в ваше приложение, включая:

- **Серверный рендеринг (SSR)**: Рендеринг HTML на сервере и гидратация его на клиенте
- **Серверные функции**: Типобезопасные HTTP-эндпоинты Axum, напрямую вызываемые с клиента
- **Горячая перезагрузка**: Быстрая горячая перезагрузка Rust во время разработки, работающая на [subsecond](https://crates.io/crates/subsecond)
- **Типизированная маршрутизация**: Легкое извлечение запросов и путей из URL
- **Многочастные формы**: Захват многочастных данных формы с клиента в типизированные Rust-структуры
- **Бинарные потоки**: Легкое добавление возможности загрузки/выгрузки файлов на бэкенде
- **SSE и WebSockets**: Сложные типы данных с состоянием для серверной коммуникации
- **Управление ассетами**: Автоматическая оптимизация ассетов для развёртывания на CDN
- **Поддержка WASM**: Развёртывание на WASM-провайдеры, такие как Cloudflare Workers
- **Разделение бандлов**: Разделение больших WASM-блобов по маршрутам
- **Генерация статических сайтов**: Генерация HTML-разметки, идеальной для блогов и статических сайтов

В настоящее время Dioxus Fullstack не предоставляет встроенных утилит для таких вещей, как базы данных, кэши, сессии и почтовые сервисы. Наш текущий фокус — завершить полировку fullstack-интеграции, прежде чем расширяться до более "полного" fullstack-решения. Вам нужно будет подключить сторонние крейты, такие как `Sqlx` и `tower-sessions`, для использования таких функций. Чтобы помочь, мы предоставляем [несколько примеров в репозитории Dioxus на GitHub](https://github.com/DioxusLabs/dioxus/tree/main/examples/07-fullstack) для начала работы.

## Горячая перезагрузка

С Dioxus наша цель — максимизировать вашу продуктивность разработчика. Dioxus Fullstack поставляется со встроенной полной поддержкой горячей перезагрузки Rust благодаря нашему движку hot-patch [subsecond](https://crates.io/crates/subsecond). Subsecond использует продвинутые техники ассемблера и линковки, позволяющие модифицировать Rust-функции во время выполнения. Вы можете добавлять новые эндпоинты, страницы и логику в ваше приложение без ручной пересборки.

<video src="/assets/07/dual-serve-hotreload.mp4" controls></video>

У Subsecond есть несколько ограничений. Для лучшего опыта мы рекомендуем модифицировать только код в "верхушке" вашего приложения. Обратите внимание, что код, который выполняется только один раз, не будет поддающимся горячей перезагрузке и потребует перезапуска приложения.

## Серверные функции

Dioxus Fullstack предоставляет простой способ коммуникации с сервером с любого клиента. Серверные функции позволяют определить функцию, которая всегда выполняется на сервере. Когда вы вызываете эту функцию с клиента, Dioxus автоматически сериализует аргументы, отправляет их на сервер, выполняет функцию на сервере, сериализует возвращаемое значение и отправляет его обратно клиенту.

```rust
// Тело функции всегда будет выполняться на сервере, поэтому мы можем делать серверные операции, такие как запросы к базе данных
#[get("/api/dog/{breed}")]
async fn fetch_dog(breed: String) -> Result<String> {
    DB.execute("SELECT url FROM dogs WHERE id = ?1", &breed)
}
```

Мы можем использовать результаты серверных функций во время серверного рендеринга вместе с гидратацией:

```rust
let url = use_loader(|| fetch_dog("poodle".to_string()))?;

rsx! {
    img { src: "{url}", alt: "A cute dog" }
}
```

Серверные функции описаны более подробно в [руководстве по серверным функциям](./server-functions.md). Помимо этого руководства, вы можете найти больше примеров fullstack-приложений в [директории examples](https://github.com/DioxusLabs/dioxus/tree/main/examples).

## WebSockets и потоки

Dioxus Fullstack поставляется с полной поддержкой Axum, и с ней специальные клиентские обработчики для таких вещей, как WebSockets и HTTP-потоки. Мы предоставляем ряд утилит, таких как `use_websocket`, для реактивного управления этими ресурсами на клиенте.

![Fullstack websockets](/assets/07/fullstack-websockets.avif)

Наш обёртчик `Streaming<T>` позволяет легко отправлять произвольные байты, текст, JSON и chunked-содержимое файлов на сервер и с сервера. Легко создавайте собственные гибридные клиент-серверные типы, реализуя `IntoRequest` и `FromResponse`!

## Серверный рендеринг

Dioxus Fullstack позволяет рендерить ваше приложение на сервере, ускоряя время загрузки для ваших пользователей и улучшая обнаружимость вашего сайта для поисковых систем, таких как Google. Серверный рендеринг (SSR) позволяет рендерить начальный HTML вашего приложения на сервере, отправляя полностью сформированный HTML-документ клиенту. Клиент затем может "гидратировать" HTML в полностью интерактивное приложение, которое может продолжать работать на клиенте без необходимости постоянного подключения к серверу.

## Ассеты

Поскольку Dioxus Fullstack интегрируется с нашим инструментом сборки DX, ваши fullstack-приложения предварительно оптимизированы для развёртывания на инфраструктуре, такой как content-distribution-networks (CDN). CDN уменьшают использование полосы пропускания и ускоряют time-to-first-byte вашего приложения для максимальной производительности. Ассеты, собранные с DX, хэшируются, позволяя клиенту бесконечно кэшировать их содержимое.
