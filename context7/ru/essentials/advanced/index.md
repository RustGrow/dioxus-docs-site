# Продвинутые темы

Этот раздел охватывает различные продвинутые темы, которые могут оказаться полезными по мере роста вашего приложения на Dioxus. Он включает темы от организации приложения с помощью пользовательских хуков до выхода за пределы Dioxus с помощью эффектов.

## Содержание

- [Пользовательские хуки](./custom-hooks.md) Помимо встроенных хуков, Dioxus позволяет создавать собственные пользовательские хуки для инкапсуляции логики, которую можно использовать в компонентах.
- [Жизненный цикл компонента](./lifecycle.md) Каждый компонент в Dioxus следует одному и тому же жизненному циклу: монтирование, сравнение и удаление. Этот раздел рассказывает, как подключиться к этому жизненному циклу.
- [Выход из абстракции](./breaking-out.md) Иногда API, предоставляемые Dioxus, недостаточны. Этот раздел рассказывает, как выйти за пределы Dioxus и использовать собственные API для манипуляции DOM или вызова JS-функций.
