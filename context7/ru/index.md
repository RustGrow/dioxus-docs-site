# Документация Dioxus

Добро пожаловать в документацию Dioxus! Dioxus — это фреймворк для создания кроссплатформенных приложений на языке программирования Rust. С одной кодовой базой вы можете создавать приложения для веба, десктопа и мобильных платформ.

## Что такое Dioxus?

Dioxus — это UI-фреймворк на Rust, который упрощает создание красивых интерактивных пользовательских интерфейсов. Он использует модель компонентов, похожую на React, с RSX (синтаксис, похожий на JSX для Rust), и поддерживает:

- **Веб-приложения** — Компиляция в WASM и запуск в браузере
- **Десктоп-приложения** — Нативные приложения с использованием WebView или WGPU
- **Мобильные приложения** — Приложения для iOS и Android
- **Фулстек** — Рендеринг на стороне сервера с серверными функциями
- **LiveView** — UI в реальном времени, рендеримые на сервере

## Пример

```rust
use dioxus::prelude::*;

fn main() {
    launch(app);
}

fn app() -> Element {
    let mut count = use_signal(|| 0);

    rsx! {
        h1 { "Счетчик: {count}" }
        button { onclick: move |_| count += 1, "Больше!" }
        button { onclick: move |_| count -= 1, "Меньше!" }
    }
}
```
