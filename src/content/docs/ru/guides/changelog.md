# История изменений

На этой странице собраны заметки о патч-релизах Dioxus. Руководства по миграции между мажорными версиями находятся в разделе [Миграция](../migration/index.md).

## Dioxus 0.7

### v0.7.7

- **Автоопределение типа JS-модуля**: Исправлена регрессия, при которой DX всегда бандлил JS-фрагменты как ESM, даже если они были CJS, UMD или обычными JS-фрагментами. Теперь DX корректно определяет тип JS-модуля и запускает esbuild с подходящими флагами.

### v0.7.6

- **Финальный релиз 0.7**: Репозиторий теперь будет публиковать критические изменения в подготовке к 0.8.
- **Автодополнение оболочки**: Добавлена команда `dx completions` для генерации автодополнений для bash, zsh, fish и PowerShell.
- **Ускоренный хотпатчинг**: Значительно ускорен запуск dev-сервера при использовании `dx serve --hotpatch`.
- **Восстановление после паники**: Веб-приложения Dioxus, которые паникуют при обработке событий, больше не «ломают» веб-страницу.
- **Новые примеры**: Добавлено 20+ новых примеров кода в репозиторий.
- **Бандлинг иконок Windows**: `dx serve` и `dx bundle` теперь поддерживают бандлинг иконок приложений Windows.

### v0.7.5

- **Исправление версий зависимостей**: Исправлена критическая проблема, при которой Dioxus не компилировался, если `Cargo.lock` указывал слишком старые версии зависимостей, таких как `futures-unordered`. Сам crate `dioxus` не обновлялся — только его зависимости.
- **Исправления хотпатчинга**: Исправлены баги, связанные с хотпатчингом, автоформатированием и бандлингом.

### v0.7.4

- **Кастомизация сборок для мобильных устройств**: Теперь можно кастомизировать все аспекты сборок iOS и Android через `Dioxus.toml`. Доступные поля смотрите в [схеме CLI](https://github.com/DioxusLabs/dioxus/blob/main/packages/cli/schema.json).
- **Интерфейс FFI**: Добавлен новый FFI-интерфейс для Kotlin, Java и Swift. Автоматически бандлит соответствующие исходные файлы в ваши мобильные сборки.

### v0.7.3

- **Новые события**: Добавлена поддержка событий `auxclick` и `scrollend`.
- **Scoped CSS и CSS Modules**: Добавлена встроенная поддержка scoped CSS и CSS Modules. Подробности см. в руководстве [Стилизация](../essentials/ui/styling.md).
- **Серверные экстракторы**: Добавлена поддержка серверных экстракторов (server-only extractors) в серверных функциях.

### v0.7.2

- **Drag & Drop**: Исправлены проблемы сериализации при drag and drop событиях.
- **Синхронные хранилища**: Исправлен deadlock в синхронных хранилищах.
- **Хотпатчинг**: Исправлен WASM-хотпатчинг и проблемы с Windows hot-patch `cdylib`.
- **Платформенные исправления**: Исправлены подписание кода macOS, проблемы с Linux-окнами, сборки Linux musl и пропущенные фреймы при fullstack-стриминге.

### v0.7.1

- **Асинхронные диалоги выбора файлов**: Диалоги выбора файлов на десктопе теперь асинхронные вместо синхронных. Это предотвращает зависание UI во время выбора файла.
- **Поддержка query string**: Серверные функции теперь используют `serde_qs` для поддержки query string.
- **Сборки только с SSR**: Добавлен флаг `--platform web2` для сборок только с SSR без гидратации.
- **iOS LaunchScreen**: Добавлена поддержка iOS LaunchScreen storyboards.

### v0.7.0

Первоначальный релиз 0.7. Полный список критических изменений и новых функций см. в [Руководстве по миграции](../migration/to-07.md), включая:

- Хотпатчинг с Subsecond
- Нативный рендеринг
- Разделение бандлов
- Примитивы Radix UI
- Fullstack-стриминг
- Новый API хранилищ

## Dioxus 0.6

### v0.6.3

- **Перевод HTML**: Исправлены проблемы в `dx html` → RSX переводе.
- **Бандлинг Windows**: Исправлен бандлинг `.exe` на Windows.
- **Горячая перезагрузка ассетов**: Исправлена обработка gitignore-нутых manganis-ассетов.
- **Горячая перезагрузка Android**: Добавлена поддержка горячей перезагрузки Android-устройств через ADB.

### v0.6.2

- **Поддержка iPadOS**: Добавлена поддержка iPadOS для `dx serve`.
- **Кэш-бустинг**: Добавлен cache-busting для `.wasm` файлов.
- **Горячая перезагрузка устройств**: `dx serve` теперь слушает на `0.0.0.0` для поддержки горячей перезагрузки на устройствах.
- **Выходная директория бандла**: Добавлена поддержка `out_dir` для `dx bundle`.

### v0.6.1

- **Динамический wasm-bindgen**: CLI теперь динамически устанавливает правильную версию `wasm-bindgen` вместо требования загрузки новой версии `dx`.
- **Устойчивость горячей перезагрузки ассетов**: Исправлена проблема, при которой горячая перезагрузка ассетов случайно ломалась на вебе.

### v0.6.0

Первоначальный релиз 0.6. Полный список критических изменений и новых функций см. в [Руководстве по миграции](../migration/to-06.md).
