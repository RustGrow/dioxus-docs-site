# Поддержка платформ

Большая часть вашего кода на Dioxus будет работать на всех платформах. Однако каждая платформа имеет свой набор функций и ограничений. Например, веб-платформа поддерживает вызов JavaScript через wasm-bindgen, а десктопная платформа поддерживает настройку внешнего вида окна вокруг приложения.

## Платформенно-специфичный код

Прежде чем погружаться в платформенно-специфичный код, важно хорошо понимать фичи (features) в Rust. Фичи позволяют добавлять код, который будет включён в сборку только если определённая фича включена.

Dioxus использует отдельную фичу для каждой платформы. Например, веб-платформа включает фичу `dioxus/web`, а десктопная платформа включает фичу `dioxus/desktop`.

В вашем файле `Cargo.toml` вы должны настроить фичу для каждой платформы, которую хотите поддерживать. Например:

```toml
[features]
default = []
web = ["dioxus/web"] # Эта фича включается при веб-сборках
desktop = ["dioxus/desktop"] # Эта фича включается при десктоп-сборках
```

После настройки фичей вы можете оборачивать ваш код в `#[cfg(feature = "web")]` или `#[cfg(feature = "desktop")]`, чтобы условно включать код для каждой платформы.

```rust
#[cfg(feature = "web")]
fn web_specific_code() {
    // Код, специфичный для веб-платформы
}

#[cfg(feature = "desktop")]
fn desktop_specific_code() {
    // Код, специфичный для десктопной платформы
}
```

## Платформенно-специфичные зависимости

Помимо платформенно-специфичного кода, вам может понадобиться настроить зависимости, которые включаются только на определённых платформах. Например, если вы строите веб-приложение, вы можете захотеть включить зависимость от крейта `wasm-bindgen` для вызова JavaScript-функций из Rust.

Вы можете добавить платформенно-специфичные зависимости как optional в вашем `Cargo.toml` и включать их с помощью таблицы `features`. Например:

```toml
# Поскольку эта зависимость optional, она не включается в сборку автоматически
wasm-bindgen = { version = "*", optional = true }

[features]
default = []
# добавление dep:wasm-bindgen включает зависимость wasm-bindgen только
# в веб-сборках
web = ["dioxus/web", "dep:wasm-bindgen"]
desktop = ["dioxus/desktop"]
```

## Содержание

Каждая глава этого руководства охватывает отдельную платформу:

- [Веб](web.md) Веб-платформа позволяет компилировать в WASM и рендерить в DOM в браузере
- [Десктоп](desktop.md) Десктопная платформа запускает ваш код нативно и рендерит с помощью webview
- [Мобильные устройства](mobile.md) Мобильная платформа использует тот же движок рендеринга, что и десктоп, но требует дополнительной настройки для мобильных устройств/эмуляторов
