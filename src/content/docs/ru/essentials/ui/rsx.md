# Введение в RSX

Приложения Dioxus состоят из небольших элементов, скомпонованных в компоненты, а затем собранных в дерево. Чтобы конструировать наши компоненты, мы используем комбинацию Rust-кода и упрощенного диалекта Rust, который мы называем "RSX".

RSX разработан так, чтобы выглядеть и ощущаться как смесь между HTML и SwiftUI:

```rust
rsx! {
    h1 { "Добро пожаловать в Dioxus!" }
    h3 { "Представлено {author}" }
    p { class: "main-content", {article.content} }
}
```

В настоящее время RSX — это основной синтаксис, который разработчики используют для создания приложений Dioxus. Есть и другие опции, но RSX имеет лучшие инструменты разработчика, такие как мгновенная горячая перезагрузка, сворачивание кода и подсветка синтаксиса.

## Макрос `rsx!`

Если вы знакомы с библиотеками вроде React или Vue, вы, вероятно, знакомы с языком разметки JSX. JSX — это альтернативная форма JavaScript, которая позволяет разработчикам смешивать JavaScript-код и XML в одном файле. Эти библиотеки полагаются на плагины компилятора для трансформации синтаксиса в чистый JavaScript-код, который затем рендерит HTML.

С Rust мы достигаем похожего опыта через использование [процедурных макросов](https://doc.rust-lang.org/reference/procedural-macros.html) (proc macros). Proc macros — это крошечные плагины компилятора, которые трансформируют токены Rust в Rust-код. Вы можете распознать, что функция является proc macro, благодаря модификатору `!`. Например, макрос `rsx!` трансформирует синтаксис RSX в Rust-код:

```rust
// Этот макрос...
rsx! {
    div { "hello {world}!" }
}

// Разворачивается в этот шаблон:
static TEMPLATE: Template = Template {
    nodes: [
        ElementNode {
            tag: div,
            children: [
                TextNode {
                    contents: DynamicText(0)
                }
            ]
        }
    ]
}
TEMPLATE.render([
    format!("hello {world}")
])
```

RSX делает *много* тяжелой работы для нас, значительно сокращая многословность декларирования UI. Он также конструирует наши UI в *наиболее* эффективном представлении, делая рендеринг чрезвычайно быстрым.

## Dioxus рендерит HTML и CSS

Мы хотим убедиться, что Dioxus легко изучить и чрезвычайно портативен. Вместо изобретения новой системы стилизации, макета и разметки мы просто решили полагаться на HTML и CSS везде. Для веба это удобно — веб-сайты уже построены с помощью HTML и CSS. На десктопе и мобильных устройствах мы поставляем рендерер, который автоматически конвертирует ваш HTML и CSS в нативные виджеты.

Наш гибридный подход HTML объединяет лучшие части фреймворков вроде Flutter и React Native. Команды получают максимальное повторное использование кода, работают с знакомым языком разметки, и AI-инструменты сразу становятся полезными. Вместо создания bespoke нативных приложений для каждой платформы команды могут просто написать свои компоненты один раз и рендерить их везде.

Наш рендеринговый движок [Blitz](https://github.com/dioxuslabs/blitz) имеет открытый исходный код и часто неотличим от браузерных движков:

![Blitz vs Safari](/assets/07/blitz-vs-safari.png)

Если вы не знакомы с HTML, это руководство поможет вам начать с основ. Для более подробной информации [документация MDN](https://developer.mozilla.org/en-US/docs/Web/HTML) — отличный ресурс. Многие инструменты предоставляют визуальные дизайнеры или AI-помощь для конструирования UI из HTML-элементов.

## Разнообразие рендереров

Dioxus чрезвычайно модулен. Поскольку представление RSX является generic, вы можете даже заменить элементы, выбирая рендеринг UI, который *не* состоит из HTML и CSS. Хотя команда Dioxus намерена поддерживать только рендереры на основе HTML/CSS, существуют сторонние рендереры, которые открывают расширенную функциональность.

Например, проект [Freya](https://freyaui.dev) рендерит дерево Dioxus с помощью рендерера Google Skia. Skia имеет архитектуру только-CPU, работает на широком диапазоне устройств и обеспечивает более глубокий контроль над UI-эффектами:

<video src="/assets/07/freya-todo.webm" controls></video>

Команда Dioxus поддерживает три first-party рендерера:

- Dioxus-Web: Веб-совместимый движок, который рендерит напрямую в HTML DOM Nodes
- Dioxus-Webview: Десктопный и мобильный движок, который рендерит в системный webview
- Dioxus-Native: Десктопный и мобильный движок, который рендерит в нативные элементы

Веб- и Webview-рендереры являются наиболее зрелыми движками, в то время как Dioxus-Native всё ещё проходит существенные улучшения.
