## Идеи для новых функций

Бросьте себе вызов, добавляя новые функции в *HotDog*.

- Добавьте анимации в ваше приложение с помощью CSS или [dioxus-motion](https://github.com/wheregmis/dioxus-motion).
- Стильзуйте ваше приложение с помощью библиотеки вроде [TailwindCSS](http://tailwindcss.com).
- Добавьте инпуты, чтобы пользователи могли загружать свои собственные фото собак.
- Сделайте его социальным! Добавьте логин, пользовательские аккаунты и ленту.
- Переделайте HotDog во что-то совершенно новое.

## FAQ

Вам может быть интересно, как конкретные функции работают в Dioxus. Давайте попробуем затронуть несколько популярных вопросов:

### Быстрый ли Dioxus?

Dioxus действительно быстрый. Dioxus построен вокруг *чрезвычайно* производительного VirtualDom. Хотя VirtualDom может звучать как ["чистые накладные расходы"](https://svelte.dev/blog/virtual-dom-is-pure-overhead), Dioxus использует оптимизации времени компиляции, которые делают его быстрее, чем почти все UI-фреймворки.

### Подходит ли Dioxus для production?

Да! Dioxus используется в production многими компаниями и проектами. Фреймворк стабилен и активно развивается. Компании вроде [Fermyon](https://www.fermyon.com), [Vercel](https://vercel.com) и многие другие используют Dioxus для своих приложений.

### Нужно ли мне знать Rust?

Да, Dioxus — это фреймворк на Rust, поэтому знание Rust необходимо. Однако если вы знакомы с React или другими современными UI-фреймворками, многие концепции переносятся напрямую. Мы рекомендуем прочитать [Rust Book](https://doc.rust-lang.org/book/) если вы новичок в Rust.

### Могу ли я использовать Dioxus только для веба?

Абсолютно! Хотя Dioxus поддерживает множество платформ, вы можете использовать его исключительно для веб-разработки. Веб-рендерер Dioxus компилируется в WASM и работает в браузере.

### Есть ли у Dioxus экосистема компонентов?

Экосистема Dioxus растет! Есть несколько библиотек компонентов и утилит, созданных сообществом. Ознакомьтесь с [awesome-dioxus](https://github.com/DioxusLabs/awesome-dioxus) для списка проектов сообщества.
