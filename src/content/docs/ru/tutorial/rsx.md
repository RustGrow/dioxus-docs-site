# Описание UI

Dioxus — это _декларативный_ фреймворк. Это означает, что вместо того, чтобы говорить Dioxus, что делать (например, «создать элемент" или «установить цвет в красный"), мы просто _декларируем_, как мы хотим, чтобы UI выглядел, используя RSX.

```rust
// define a component that renders a div with the text "Hello, world!"
fn App() -> Element {
    rsx! {
        div { "Hello, world!" }
    }
}
```

Здесь мы используем макрос `rsx!` для _декларирования_ того, что мы хотим элемент `div`, содержащий текст `"Hello, world!"`. Dioxus берет RSX и конструирует из него пользовательский интерфейс.

## Редактирование RSX с горячей перезагрузкой

При использовании `dx serve` RSX вашего приложения автоматически подвергается горячей перезагрузке при редактировании и сохранении файла. Вы можете редактировать структуру RSX, добавлять новые элементы и стилизовать разметку без полной пересборки.

Всякий раз, когда вы редактируете *Rust* код, `dx` автоматически инициирует «полную пересборку" вашего приложения.

Начиная с Dioxus 0.7, вы можете запустить `dx serve --hotpatch` для включения горячей перезагрузки Rust-кода во время выполнения.

Для подробного руководства о том, что можно и что нельзя перезагружать горячим способом, ознакомьтесь с [руководством по горячей перезагрузке](../essentials/ui/hotreload.md).

## RSX — это просто HTML

Dioxus предоставляет макрос `rsx! {}` для сборки `Element`-ов в вашем приложении. Макрос `rsx! {}` в первую очередь говорит на HTML: веб, десктоп и мобильные рендереры Dioxus от первого лица все используют HTML и CSS как технологии макета и стилизации.

Это означает, что вы можете использовать свои знания веба и строить свое приложение с помощью `div`, `span`, `img`, `style`, `button` и многого другого.

Синтаксис RSX является «строгой" формой Rust, которая использует синтаксис `Struct` Rust для сборки элементов:

```rust
rsx! {
        div {
            class: "bg-red-100"
        }
    }
```

Элементы в RSX немного отличаются от синтаксиса Rust struct: они также могут содержать дочерние структуры, размещенные сразу после финального атрибута.

```rust
rsx! {
        div { class: "bg-red-100",
            button {
                onclick: move |_| info!("Clicked"),
                "Click me!"
            }
        }
    }
```

Кроме того, все строки в кавычках в RSX подразумевают `format!()` автоматически, поэтому вы можете определить переменную вне разметки и использовать ее в строках без явного вызова format:

```rust
rsx! {
        div { "Breed: {breed}" }
    }
```

Любое выражение, которое может быть отрендерено в String, может быть включено напрямую в RSX. RSX также принимает `Option<Element>` и итераторы элементов:

```rust
rsx! {
// Anything that's `Display`
        {"Something"}

Optionals
        {show_title.then(|| rsx! { "title!" } )}

// And iterators
        ul {
            {(0..5).map(|i| rsx! { li { "{i}" } })}
        }
    }
```

Dioxus предоставляет два элемента синтаксического сахара для этих распространенных случаев: циклы `for` и цепочки `if`. Эти блоки возвращают содержащийся RSX напрямую.

```rust
rsx! {
        if show_title {
            "title!"
        }

        ul {
            for item in 0..5 {
                li { "{item}" }
            }
        }
    }
```

Для списков Dioxus использует атрибут `key` для обеспечения сравнения правильных элементов между рендерами. Если вы забудете добавить атрибут `key` к элементу списка, вы можете столкнуться с проблемами производительности и управления состоянием. Обычно вы можете найти уникальный ключ для дифференциации элементов списка:

```rust
rsx! {
        for user in users {
            div {
                key: "{user.id}",
                "{user.name}"
            }
        }
    }
```

## Добавление UI в наше приложение *HotDog*

Давайте добавим базовый UI в наше приложение. Мы добавим заголовок, изображение тела для фото собаки и несколько базовых кнопок.

```rust
#[component]
fn App() -> Element {
    rsx! {
        div { id: "title",
            h1 { "HotDog! 🌭" }
        }
        div { id: "dogview",
            img { src: "https://images.dog.ceo/breeds/pitbull/dog-3981540_1280.jpg" }
        }
        div { id: "buttons",
            button { id: "skip", "skip" }
            button { id: "save", "save!" }
        }
    }
}
```

Наше приложение начинает обретать форму!
