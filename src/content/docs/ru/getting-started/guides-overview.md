# Руководства Dioxus

Эти руководства основаны на темах, рассмотренных в главе [основные концепции](../essentials/index.md), и содержат более подробные объяснения и примеры. Хотя мы рекомендуем всем прочитать либо весь [туториал](../tutorial/index.md), либо [основные концепции](../essentials/index.md) по мере изучения Dioxus, эти руководства предназначены для пользователей, которые хотят углубиться в конкретные темы по мере необходимости.

## Инструменты

Dioxus предоставляет набор инструментов для упрощения создания кроссплатформенных приложений. [`dioxus-cli`](https://crates.io/crates/dioxus-cli) — это основной инструмент для сборки, запуска и управления приложениями Dioxus. Руководство по [инструментам](../guides/tools/index.md) содержит дополнительную информацию о различных инструментах, доступных в экосистеме Dioxus.

## Платформы

При создании приложения с Dioxus большая часть кода приложения может быть платформонезависимой. Когда вам нужно взаимодействовать с платформенно-специфичными функциями, Dioxus предоставляет различные бэкенды платформ, которые помогут вам в этом. Руководство по [платформам](../guides/platforms/index.md) содержит дополнительную информацию о различных платформах, поддерживаемых Dioxus.

## Публикация

После завершения создания вашего приложения [руководство по публикации](../guides/deploy/index.md) содержит обзор того, как упаковать и распространить ваше приложение. Оно также включает информацию о доступных опциях конфигурации для бандлинга.

## Кастомный рендерер

Если вы готовы углубиться в создание собственного рендерера для Dioxus, [руководство по кастомному рендереру](../guides/utilities/custom-renderer.md) содержит обзор того, как начать.

## Миграция

Если вы обновляетесь со старой версии Dioxus, [руководства по миграции](../migration/index.md) содержат информацию о критических изменениях и о том, как обновить ваш код для работы с последней версией Dioxus.
